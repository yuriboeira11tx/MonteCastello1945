Windows de 64 bits · Teclado e mouse
Fones de ouvido recomendados para a ambientação.

  1. Escolha o pacote do jogo

    No Release, procure a seção Assets e baixe o arquivo da versão para Windows. Source code (zip) e Source code (tar.gz) são o código-fonte, não o jogo pronto.

  2. Extraia a pasta completa

    Descompacte o pacote com um extrator compatível com seu formato. Mantenha o executável, a pasta MonteCastello1945_Data e os demais arquivos juntos.

  3. Abra o executável e inicie

    Dentro da pasta extraída, execute MonteCastello1945.exe. No menu, escolha Novo jogo e siga as orientações da caderneta.

Não apareceu nenhum arquivo para baixar?

O pacote pode ainda não ter sido publicado. Aguarde a disponibilização nos Releases. Os arquivos de código-fonte não substituem o executável.

Leve seu relatório
para a pesquisa.

A prancheta final reúne os resultados da sua partida. O código permite encaminhar esses dados junto da avaliação.

Relatório do participante
  1. Na prancheta final, preencha Nome do aluno.
  2. Clique em Confirmar nome e emitir relatório.
  3. Clique em Copiar JWT.
  4. Abra o formulário de experiência e cole o texto completo no campo do relatório.
  5. Responda às demais perguntas e envie o formulário.

Use uma identificação consistente nos formulários e no jogo. O código curto exibido na prancheta não substitui o texto copiado pelo botão Copiar JWT.

Sobre o trabalho

Investigar. Relacionar.
Compreender.

Monte Castello: 1945 é um protótipo de jogo sério 3D desenvolvido como Trabalho de Conclusão de Curso em Sistemas de Informação na Universidade Federal de Santa Maria, campus Frederico Westphalen.

O objetivo é explorar o potencial dos jogos como apoio ao ensino e à aprendizagem de História. O jogador assume o papel de pesquisador: examina fontes, reúne evidências e organiza dossiês sobre a participação brasileira na Segunda Guerra Mundial.

Estado do projeto

Um começo, com caminho para expandir.

Esta versão apresenta o recorte que foi possível desenvolver no tempo disponível para o TCC: o acervo, a reconstrução do Itapagé e a visita ao acampamento. A intenção futura é ampliar a experiência para acompanhar toda a trajetória da FEB. O protótipo atual ainda não representa a campanha completa.

Dúvidas frequentes

Antes de continuar.

Preciso saber a história da FEB para jogar?

Não. Responda ao pré-teste com o que já sabe. Durante o jogo, leia os documentos e explore os objetos para construir sua pesquisa.

Posso jogar no celular ou no navegador?

Esta página funciona no celular, mas o pacote do protótipo é para Windows de 64 bits. O jogo não é executado dentro desta página.

Marcar uma etapa envia o formulário?

Não. As caixas servem apenas para acompanhar seu percurso neste navegador. Abra o Google Formulário, preencha e use o botão Enviar nele.

E se eu não conseguir terminar o jogo?

Use o formulário de experiência para descrever até onde chegou e o problema encontrado. Se não recebeu um relatório final, informe isso em vez de inventar um código.

Onde encontro os arquivos do projeto?

O código e a documentação estão no repositório do GitHub (abre em nova aba). Para apenas jogar, utilize o pacote dos Releases.
